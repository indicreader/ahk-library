                    🚀 DESKTOP STUDY & AUTOMATION WORKFLOW SUITE 🚀

Below is your quick-start guide for your custom AutoHotkey background tools. 
Make sure the main script file is running (green 'H' icon in your system tray).

-------------------------------------------------------------------------------
SCRIPT NAME               SHORTCUT          ACTION
-------------------------------------------------------------------------------
Quick Slang Manager      Ctrl+Shift+A      Opens a popup dashboard to quickly add 
                                            custom text contractions or short macros 
                                            permanently to your active library.

Universal CSV Scraper     Alt+X             Silently clips highlighted text from 
                                            ANY document reader (Okular, Adobe, 
                                            Edge, Chrome) and dumps it cleanly 
                                            into an auto-named spreadsheet row.

Folder Alchemist Cleaner  Ctrl+Shift+O      Instantly sorts the current messy 
                                            File Explorer directory into clean, 
                                            IDM-aligned categorical subfolders 
                                            while dissolving direct duplicates.
-------------------------------------------------------------------------------

💡 SYSTEM NOTES:
• Extracted CSV notes are saved inside the "Extractions" folder on your Desktop.
• The CSV files are automatically named after the actual book or PDF title.
• Close your spreadsheet before using Alt+X, or Windows will lock the file!
